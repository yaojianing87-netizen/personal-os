# Diving

一个本地优先的浏览器前端原型。直接用浏览器打开 `index.html` 即可运行，不需要安装依赖或启动服务器。

## 当前可用功能

- 模块页面导航
- 侧栏底部 Feedback：感谢语、三个联系邮箱的一键复制、反馈输入及完整反馈内容复制；通过默认邮件客户端打开草稿，由用户确认发送
- 外观主题与颜色调整
- Notes：无边记风格的看板缩略图总览与点阵画布；支持便签、文字、图片和手绘的添加、编辑、移动、调整大小、删除、撤销重做，以及画布缩放和漫游
- Inspiration：灵感便签的创建、编辑、删除、置顶、换色和自动保存
- 可切换任意年份和月份的日历；同日多条日程与日期备注的创建、编辑、删除及本地保存
- 任务的创建、编辑、优先级设置、完成、删除与本地保存；任务页始终显示“今日、本周、之后”三组，首页“今日任务”与今日分组共用内容和完成状态，不截断为前四条
- 首页“专注”面板与“专注模式”共用同一个倒计时，支持开始、暂停、继续、重置及空闲时设置时长；切页和刷新后保持同步
- 旅行地图：点击地图识别附近地点，确认名称后选择“想去／已去／正在计划”；点击已保存的标记可调整分类，列表每个地点右侧的叉号可删除地点及其关联内容

## 本地数据

数据保存在当前浏览器的 `localStorage`：

- `atelier-appearance`
- `atelier-ideas`
- `atelier-note-boards`（看板及可恢复的已删除看板）
- `atelier-notes`（保留的旧笔记备份）
- `atelier-calendar-notes`
- `atelier-tasks`
- `atelier-focus-intention`（独立的专注事项文字）

Notes 与 Inspiration 分开保存。首次使用新看板时，每篇旧笔记会迁移为一张看板，标题和正文保留，旧数据不被覆盖；之后删除看板不会再次导入旧笔记。看板标题与内容自动保存，删除看板后可在总览点击“撤销删除看板”恢复，画布内容可在本次编辑期间撤销和重做。清除浏览器站点数据会删除这些内容。

在画布工具栏添加内容，编辑文字后拖动所选内容上方的“移动”手柄改变位置，拖动右下角调整大小；也可双击空白处添加文字。使用漫游工具拖动画布，或通过底部按钮缩放和适合内容。图片支持 10 MB 以内的 PNG、JPEG 和 WebP，插入时会压缩保存；浏览器存储空间有限，保存失败时会明确提示。

画笔有独立的颜色图卡，可选预设色、系统颜色选择器或输入六位十六进制颜色；画笔图标、色卡和实际笔迹使用同一个颜色。便签底色单独设置，旧版图形会转为便签并保留文字和位置。橡皮仅处理手绘笔迹：对象橡皮接触即删除整个原始笔画，精准橡皮只擦除覆盖部分；精准擦成多段的原始笔画仍可整体擦除。橡皮提供 8、20、40、64 px 四种大小，一次连续擦除可一次撤销，结果自动保存。

任务分组沿用截止日期规则：“今日”包含今天到期及已逾期的任务，“本周”包含之后七天内到期的任务，其他日期及未设置日期的任务归入“之后”。三个分组即使没有任务或筛选结果为空，也保留标题和新建入口。首页显示今日分组的全部任务，计数为今日尚未完成的数量；左侧任务导航仍显示全部未完成任务数量。跨过午夜后会自动更新归组。

首页专注面板的读数、控制和进度直接复用完整专注模式。进行中可以暂停、继续或重置；重置会按原有确认流程放弃本次计时，不计入专注记录。需要更换时长时先重置，再点击“设置时长”。只有完整结束的专注才记录一次，不会因为两个面板同时显示而重复计时或累计。

专注模式中的“当前任务”是可自由输入的专注事项，与任务清单独立；直接编辑会自动保存并同步到首页，计时中和暂停时也能修改文字，剩余时间、开始时间和时长保持不变。“设置事项与时长”弹窗同样支持自由输入，计时中仅锁定时长。第一次使用会保留原先选择的任务名称作为初始文字；之后编辑或清空都不会新增、修改或完成任务清单中的任务。完整结束时，专注记录保存最终的事项文字，已有记录保持不变。

Feedback 不将评语或回复邮箱写入 localStorage、sessionStorage 或数据库；切换工作台页面时保留在内存中，返回后可继续填写，刷新或关闭后清空。邮箱旁的“复制邮箱”可分别复制 `yaojianing87@gmail.com`、`yjn0611@qq.com` 和 `a2930316463@163.com`。填写反馈后点击“打开邮件发送”，邮件草稿以 Diving 为主题品牌、Gmail 为收件人、QQ 和 163 为抄送地址，包含反馈类型、正文和选填的回复邮箱；需要用户在邮件应用中确认发送。未配置邮件应用时，可复制邮箱和完整反馈内容后手动发送。页面只提示已请求打开邮件应用，不宣称邮件已发送或送达。

旅行地图支持两种添加方式：右上角“添加地点”按名称搜索，或直接点击地图位置进行地址识别。地图弹窗可修改名称与国家／地区，再选择分类保存；已保存标记再次点击可更换分类，不重复创建同一位置的地点。新地点使用实际点击的坐标保存。地址识别采用 [Nominatim Reverse API](https://nominatim.org/release-docs/latest/api/Reverse/)，结果为附近地点，用户需确认；请求有防抖、限速、取消、超时与会话缓存，失败时可手动填写名称继续添加。

三个地点列表右侧的“×”与地图删除入口共用确认弹窗，取消不修改数据，确认后同步删除地点、关联景点、照片和待办，刷新计数和地图标记。右上角“添加景点”已移除，每个目的地下的“添加景点”仍保留。

## 验证

本项目暂未引入测试框架。每次改动至少应执行：

1. JavaScript 语法验证。
2. 静态控件与 DOM 标识检查。
3. 浏览器中的手动交互检查。

## 当前限制

- 目标模块仍处于原型阶段。
- 壁纸上传只在当前浏览器会话预览，不会持久保存。
