# Atelier Hour / Personal OS Prototype

一个本地优先的浏览器前端原型。直接用浏览器打开 `index.html` 即可运行，不需要安装依赖或启动服务器。

## 当前可用功能

- 模块页面导航
- 外观主题与颜色调整
- 灵感便签的创建、编辑、删除与本地保存
- 2026 年 11 月日历备注的创建、编辑、删除与本地保存
- 仪表盘任务的临时添加、完成状态与数量同步

## 本地数据

数据保存在当前浏览器的 `localStorage`：

- `atelier-appearance`
- `atelier-ideas`
- `atelier-calendar-notes`

清除浏览器站点数据会删除这些内容。任务目前只在当前页面会话中保留。

## 验证

本项目暂未引入测试框架。每次改动至少应执行：

1. JavaScript 语法验证。
2. 静态控件与 DOM 标识检查。
3. 浏览器中的手动交互检查。

## 当前限制

- 日历仅显示 2026 年 11 月，月切换尚未开发。
- 任务、笔记和目标模块仍处于原型阶段。
- 壁纸上传只在当前浏览器会话预览，不会持久保存。
